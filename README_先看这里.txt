近零碳智慧服务区｜轻奢多页面优化版

打开方式
1. 将整个压缩包解压到本地文件夹，不要在压缩包内直接打开。
2. 使用 Edge 或 Chrome 双击 index.html；按 F11 可全屏展示。
3. assets 文件夹中的三维引擎、数据、图片与视频都是本地资源，请与网页放在一起。
4. 无需安装 Node.js、Python、MATLAB 或网络依赖。

曲线说明
默认“平滑趋势”用于展示整体变化，并以圆点保留原始极值。
日内曲线使用 ±1.15 小时窗口，动态量使用 ±0.12 秒窗口，已标注事件两侧分开处理。
点击“原始曲线”可查看实际采样输出；时间轴、指标、悬停读数一直使用原始数值。
17 张原始仿真图保存在相应成果页的“原始仿真图”区域，支持放大及下载。

三维场景
左侧系统按钮联动视角和设备配置，可点击具体设备查看信息。
支持全景、俯视、环绕、能流显隐、日景/夜景、场景时间轴及全屏展开。
新增“能流视图”：建筑和设备半透明显示，便于观察 16 条整理后的电、水、热线路。
电力为绿色、水为蓝色、热为金色，白色箭头标明方向，圆点标明汇接。
三维设备和材质补充了阀门、法兰、通风格栅、充电防撞柱和铺装等细节；能流为展示示意，不作为施工管线。
运行工况选择区已移除；三维能流为程序化示意，不代表现场实时数据。
若浏览器不支持 WebGL，显示系统结构备用图，其他仿真页面仍可使用。
